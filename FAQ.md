# Frequently Asked Questions: AstroCare Space Mission Console

### 1. What is AstroCare Space Mission Console?
NASA mission telemetry and biometric monitoring console with real-time astronaut vitals.

### 2. What technology stack does it use?
Built with FastAPI, MongoDB Atlas, React / TypeScript, Chart.js.

### 3. Where is this project deployed?
Hosted live at: https://avishjain9.github.io/23-nasa/

### 4. How can I run it locally?
Follow the installation and setup guide provided in [docs/SETUP.md](docs/SETUP.md) or the repository `README.md`.
