# Technical & Aerospace Glossary

- **OWLT**: One-Way Light Time, the duration required for a radio signal to travel between spacecraft and Earth.
- **DTN**: Delay-Tolerant Networking, communications architecture designed to handle extreme latency and disconnections.
- **SQA**: Signal Quality Analysis, algorithms evaluating physiological plausibility and sensor artifacts.
- **EVA**: Extravehicular Activity, astronaut spacewalk outside the spacecraft or habitat.
- **DSN**: Deep Space Network, NASA's international array of giant radio antennas supporting interplanetary missions.
- **HMAC**: Hash-based Message Authentication Code, cryptographic verification of payload authenticity.
